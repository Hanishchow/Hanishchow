### What I'm building

**[hivemind](https://github.com/Hanishchow/hivemind)** — Claude Code plans and reviews; free
opencode workers do the grunt work. Parallel agent swarms with git-worktree isolation and a
one-JSON-line worker contract, so raw agent streams never flood the orchestrator's context.
Submitted upstream to [anthropics/skills](https://github.com/anthropics/skills/pull/1628).

**[neroai](https://github.com/Hanishchow/neroai)** — a biologic LLM where the decision-making
lives in a cognitive state machine rather than the language model, which is left to render.

**[crispr-multiplex-optimizer](https://github.com/Hanishchow/crispr-multiplex-optimizer)** —
optimizes 10-50 simultaneous CRISPR edits against ML guide predictions and real delivery
constraints.

**[cosmic-sync](https://github.com/Hanishchow/cosmic-sync)** — gravitational N-body physics meets
Kuramoto phase coupling in one synchronization engine.

**[print-kiosk-desktop](https://github.com/Hanishchow/print-kiosk-desktop)** — a Windows print
kiosk that actually prints: QR upload, UPI payment, staff confirmation.

**[city-shield](https://github.com/Hanishchow/city-shield)** — Bengaluru citizen emergency
platform. One incident record, shared by every responding agency.

### Contributing upstream

**[pymol-claude-plugin](https://github.com/stepdasha/pymol-claude-plugin/pull/1)** — a plugin that
drives PyMOL from plain English. Failed PyMOL commands were coming back to the model as successes,
so it kept building on state that didn't exist; fixed that and the shared-state races that could
corrupt a session for good. Added a tool that ray-traces the viewport so the model can look at what
it actually made. 79 tests against real PyMOL.
